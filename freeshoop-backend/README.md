# 🥬 Freshoop – Fruits & Vegetables E-Commerce Platform

Freshoop is a full-stack e-commerce web application designed to simplify the online shopping experience for fresh fruits and vegetables. The platform allows customers to explore products, browse categories, filter items, read reviews, and place orders online.

The application features two primary roles: **Admin and User**. Administrators can manage the store by uploading and managing products, while customers can browse available products, add items to their cart, place orders, and share their feedback through ratings and reviews.

This project was developed as a hands-on learning experience to strengthen my knowledge of **Java, Spring Boot, Spring Security, React.js, and full-stack application development**, while implementing real-world e-commerce functionalities.

## 🚀 Key Features

### 👨‍💼 Admin Panel

- Add, upload, and manage fruits and vegetable products.
- Manage product details, pricing, quantities, and availability.
- Organize products based on categories.
- Manage the store's product inventory.

### 🛒 User Features

- Browse and explore available fruits and vegetables.
- View detailed product information.
- Filter and search products based on different criteria.
- Add products to the shopping cart.
- Place orders online.
- View and interact with product ratings and reviews.
- Share comments and ratings based on shopping experiences.

### 🔐 Authentication & Security

- User authentication and authorization.
- Role-based access control for Admin and User.
- Secured backend APIs using Spring Security.
- Protected application routes and resources.

### ⭐ Additional Functionalities

- Product categorization and filtering.
- Product ratings and customer reviews.
- Dynamic product management.
- REST API integration between frontend and backend.
- Responsive user interface.

## 🏗️ Project Architecture

The application follows a client-server architecture:

- **Frontend:** React.js provides the user interface and communicates with the backend through REST APIs.
- **Backend:** Spring Boot handles business logic, authentication, authorization, and API requests.
- **Database:** MySQL stores user information, product details, categories, orders, and customer reviews.
